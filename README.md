# 文件标签管理器 (File Tagger)

> **一个用标签管理本地文件的小工具** —— 给文件打标签、按标签找文件，
> 不用再靠"文件夹套文件夹"来整理。
>
> 单文件 Tkinter 程序，Windows，中文界面（**英文界面正在做**）。

---

## ★ 这是个什么程序

**★ 解决的问题**：
> 一个文件只能放在一个文件夹里，但你**想按很多种方式找它** ——
> "这个是工作用的""这个是给客户的""这个是素材"……
> 文件夹**只能选一个**，标签**可以贴很多个**。

**★ 它能做什么**：

| 功能 | 说明 |
|---|---|
| **给文件打标签** | 一个文件可以贴多个标签，随手改 |
| **按标签找文件** | 点标签就筛出来，多个标签可以叠加 |
| **标签星图** | 标签之间的父子关系**画成图**，直接拖 |
| **自动标签** | 按文件名/路径规则**自动打**（比如"含'发票'的 → 财务"）|
| **文件索引** | 给目录建索引，**几十万文件也秒查** |
| **悬浮球** | 一个小球浮在桌面上，显示网速/硬盘/内存，**左键出菜单** |
| **深色模式** | 晚上不刺眼（★ 这条是用户最重要的需求之一）|
| **插件系统** | 别人可以写插件加功能，**不用改主程序** |
| **多语言** | 中文 / English（框架已好，**欢迎补充翻译**）|

## ★ 怎么跑起来

### ★ 方式一：直接下 exe（最简单，推荐）

**★★ 下载地址**：
**★★★ 两种下载方式**（★ 内容一模一样，挑快的）：

| 从哪儿下 | 链接 | 适合 |
|---|---|---|
| ★ **Gitee**（国内快）| **[文件标签管理器.exe](https://gitee.com/zecard/file-tagger/releases/download/v26/文件标签管理器.exe)** | ★ **国内用户** |
| **GitHub** | **[FileTagger-v26.exe](https://github.com/ZEcard17/file-tagger/releases/download/v26/FileTagger-v26.exe)** | 国外 / 访问 GitHub 快 |

**（93 MB，双击就跑，不用装 Python）**

**★ 系统要求**：Windows 10 / 11（64 位）

**★★★ 杀毒软件可能误报** —— 这是 Python 打包的通病，
不是真的有病毒（**源代码全在这个仓库里，可以自己看**）。
详见 [Releases 页面的"已知问题"](https://gitee.com/zecard/file-tagger/releases)。

### ★ 方式二：从源码跑（需要装 Python）

```bash
# 1. 需要 Python 3.10+（开发用的是 3.12）
python --version

# 2. 装依赖（只有三个是必需的）
pip install pillow tkinterdnd2 pywin32

# 3. 跑
python AIxiede.py
```

**★ 可选依赖**（不装也能跑，只是少功能）：

| 库 | 少了它会怎样 |
|---|---|
| `pymupdf` | PDF 不能预览 |
| `python-docx` / `openpyxl` | Office 文件不能预览 |
| 7-Zip（`7z.exe`）| 压缩包不能直接看里面 |

**★ 关于依赖放在哪儿**：
程序会**按顺序**找依赖目录：
```
① 程序目录/libs
② exe 旁边/libs
③ 系统 Python 环境
```
所以你可以 `pip install pillow -t libs` **把库装在程序旁边**（绿色版做法）。

## ★ 怎么用（30 秒上手）

```
① 打开程序 → 「浏览…」选一个文件夹
② 左边是分类、中间是文件列表、右边是标签库
③ 选中文件 → 点标签 → 就打上了
④ 点标签库里的标签 → 只看打了这个标签的文件
⑤ 拖悬浮球到顺手的位置 → 以后一直在那儿
```

**★ 详细说明**：见 `看这里-文件夹说明.md`

## ★ 项目结构

```
AIxiede.py                      ← 主程序（3.7 万行）
AIxiede拆分开/程序分块/          ← 拆出来的模块（16 个）
    TagStore.py                    数据层（标签/文件/分类的数据库读写）
    i18n.py                        多语言框架
    _单位换算.py                    字节/速度换算
    _背景图工具.py                  背景图 + 颜色工具
    _电子书和缓存.py                电子书元数据 / 视频缩略图 / 缓存清理
    *Dialog.py                     各种对话框
图标资产/                        ← 图标数据（外置，省内存）
语言/                            ← 语言文件（**加语言就是加一个 json**）
    zh_CN.json                     中文（原文，运行时不读）
    en_US.json                     English
插件/                            ← 插件目录（放 .py 就能加载）
文档-公开发布/                    ← ★ **开发文档**（见下）
```

## ★ 数据存在哪儿（**重要：你的数据不会上传**）

**★ 程序的数据**（标签、索引、设置）**存在你自己的电脑上**：

| 内容 | 位置 |
|---|---|
| 设置 | `%USERPROFILE%\.file_tagger_settings.json` |
| 数据库 | 由上面那个文件里的 `data_dir` 指定（**你自己选**）|
| 打包成 exe 后 | `%LOCALAPPDATA%\AIxiede\` |

**★★ 数据库里有你的文件路径和标签 —— 那是你的隐私，程序不会往外传。**
（★ 而且 `.gitignore` **明确挡住**了这些文件，**不会进版本库**。）

**★ 网络相关的功能只有两个，都是你主动开的**：
- **CloudDrive2 集成**（连本机 `localhost:19798`，**你自己的网盘客户端**）
- 无其他联网行为
