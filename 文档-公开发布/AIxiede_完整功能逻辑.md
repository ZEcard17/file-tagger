# AIxiede 文件标签管理器 — 完整功能逻辑文档

> 本文档面向普通用户，以「操作 → 效果」的方式说明每个功能的作用。
> 什么点一下、拖一下会怎样，都写清楚了。

---

## 一、整体布局

程序从左到右分四列：

```
┌────────────┬──────────────────┬──────────────┬────────────────┐
│  分类库    │    文件列表      │   预览窗格   │   标签库        │
│（上半部分）│  （主区域）       │  （右侧）    │ （星图缩略图）  │
│  文件树    │                  │              │                │
│（下半部分）│                  │              │                │
└────────────┴──────────────────┴──────────────┴────────────────┘
```

- **分类库（左上）**：按分类组织标签
- **文件树（左下）**：目录结构，导航用
- **文件列表（中间）**：显示文件缩略图或列表
- **预览窗格（右侧）**：选中文件后显示内容
- **标签库（最右）**：星图缩略图，勾选标签筛选

## 二、文件列表操作

### 2.1 单击选中一个文件
- **效果**：在文件列表中显示为高亮，右侧预览窗格显示文件内容
- **如果文件是图片**：显示图片缩略图（可随窗格宽度自动缩放）
- **如果文件是视频**：显示视频封面缩略图（后台解码第一帧）
- **如果文件是 PDF**：连续滚动显示所有页面（滚轮浏览）
- **如果文件是文本**：直接显示文本内容
- **如果文件在网盘**：显示文件信息，提供「拷到本地再打开」按钮

### 2.2 双击打开文件
- **效果**：用系统默认程序打开文件
- **不经过预览，直接用系统程序**：如用看图软件打开图片、用视频软件打开视频等

### 2.3 右键文件
弹出一个菜单，包含以下操作：

| 菜单项 | 点击效果 |
|--------|----------|
| 「打开」 | 用系统默认程序打开文件 |
| 「在文件资源管理器中显示」 | 打开系统资源管理器，定位到该文件 |
| 「复制路径」 | 把文件路径复制到剪贴板 |
| 「属性」 | 弹出一个窗口，显示文件的详细信息（大小、修改时间、标签等） |
| 「去除标签」 | 弹出一个对话框，可以选择要从文件中移除的标签 |
| 「把标签全部加入标签盒」 | 把这个文件身上的所有标签一次性放进标签盒（方便批量打标） |

### 2.4 框选文件（鼠标拖动）
- **效果**：拉出一个蓝色方框，框住的文件被选中（高亮）
- **可以配合 Ctrl**：按住 Ctrl 再单击，可以在已有选中的基础上加选/减选
- **框选后再右键**：可以对多个文件一起操作

## 三、标签系统

### 3.1 标签条（窗口底部）

**显示位置**：窗口底部状态栏旁边，有一个「🏷 标签条」按钮

**点击「🏷 标签条」按钮**：
- 第一次点 → 标签条展开，显示当前文件身上的所有标签
- 第二次点 → 标签条收起

**标签条里的标签可以点击**：
- **左键点击标签** → 筛选：只显示拥有这个标签的文件
- **右键点击标签** → 屏蔽：隐藏拥有这个标签的文件
- **配合范围选项**：可以选「当前视图范围内」或「整个数据库」

**标签条右侧的信息**：
- 显示当前视图有多少文件、多少标签
- 例如：「图本 · 12345 个文件」

### 3.2 标签盒（右下角按钮）

**点击「🏷 标签盒」按钮** → 弹出一个独立的窗口

#### 标签盒的基本操作

| 操作 | 效果 |
|------|------|
| **把标签拖进盒子里** | 从标签库/星图拖拽标签到标签盒，松开鼠标，标签就进入盒子 |
| **从盒子拖出标签** | 把标签从盒子拖到文件列表里的文件上，给文件打上这个标签 |
| **框选标签** | 在盒子空白处拖动，拉出一个方框，框住的标签一起被选中（显示蓝边） |
| **Ctrl + 点击标签** | 一个一个加选/减选选中状态 |
| **点击空白处 / 按 Esc** | 取消所有选中 |
| **右键选中的标签** | 菜单：「✖ 把选中的这 N 个一起移出盒子」 |
| **拖拽选中的多个标签** | 可以批量拖到文件上，一起给文件打多个标签 |

#### 标签盒分格功能

点击盒子顶部的「▦ 分格设置」按钮：

| 操作 | 效果 |
|------|------|
| 选择「↔ 横着分」 | 把盒子分成左右几格（自己定数量） |
| 选择「↕ 竖着分」 | 把盒子分成上下几层（自己定数量） |
| 点「＋ / －」 | 增加/减少格子数量 |
| 把标签拖进某个格子 | 标签只属于那个格子，方便分类管理 |

#### 标签盒工具栏按钮

| 按钮 | 点击效果 |
|------|----------|
| 「＋ 从标签库勾选」 | 弹出一个列表，勾选标签放进盒子 |
| 「⤢ 摊开一点」 | 把盒子里的标签排列得更稀疏 |
| 「▦ 分格设置」 | 设置横分/竖分、格子数量 |
| 「✖ 清空盒子」 | 把所有标签从盒子里移除 |

### 3.3 标签星图（独立窗口）

**打开方式**：点击标签库顶部的「🌌 标签星图」按钮

#### 星图里的基本操作

| 操作 | 效果 |
|------|------|
| **单击一个标签方块** | 选中该标签，底部显示它的上下游标签 |
| **双击一个标签方块** | 在文件列表中显示拥有这个标签的所有文件 |
| **鼠标滚轮** | 缩放星图（像 GeoGebra 那样，标签大小不变，只改变距离） |
| **按住鼠标中键拖动** | 平移星图画布 |
| **拖动一个标签方块** | 移动该标签在星图中的位置（松开鼠标确认） |
| **Shift + 拖动标签** | 把标签放进标签盒 |
| **Ctrl + 拖动多个标签** | 一起拖动多个选中的标签 |

#### 星图底部按钮

| 按钮 | 点击效果 |
|------|----------|
| 「＋ 加父级标签…」 | 给选中的标签添加父级标签（弹窗勾选） |
| 「＋ 加子级标签…」 | 给选中的标签添加子级标签（弹窗勾选） |
| 「去除关系」 | 移除选中的上下游关系 |
| 「改颜色」 | 改变选中标签的显示颜色 |
| 「改名字」 | 给选中标签改名 |
| 「新建标签」 | 在星图空白处创建一个新标签 |
| 「删除标签」 | 删除选中的标签（如果有文件用它，会提示） |
| 「保存」 | 保存所有修改到数据库 |
| 「缩放 → 适应窗口」 | 自动缩放让所有标签都显示在窗口内 |

### 3.4 标签库（最右侧栏）

**显示内容**：所有标签的缩略图列表（星图那种形式）

#### 标签库里的操作

| 操作 | 效果 |
|------|------|
| **单击一个标签** | 高亮选中该标签 |
| **Ctrl + 单击** | 多选/取消多选标签 |
| **双击一个标签** | 在文件列表中显示拥有这个标签的所有文件 |
| **把标签拖到文件上** | 给文件打上这个标签 |
| **拖拽标签到标签盒** | 把标签放进标签盒 |
| **右键标签** | 菜单：「在星图里打开」「改名字」「改颜色」「删除」 |

#### 标签库顶部搜索栏
- 输入文字，按回车 → 搜索标签名
- 搜索结果高亮显示

#### 标签库顶部工具栏按钮

| 按钮 | 点击效果 |
|------|----------|
| 「🌌 标签星图」 | 打开标签星图编辑器 |
| 「＋ 新建标签」 | 创建一个新标签 |
| 「显示/隐藏 标签库」 | 显示或隐藏右侧整列标签库 |

## 十四、常见问题处理

### Q: 预览窗格里视频/图片显示不出来
A: 可能原因：
1. 网盘文件需要点击「拷到本地再打开」
2. 视频编码不支持
3. 图片格式不支持

### Q: 拖拽标签到文件上没反应
A: 确保拖拽的目标是文件列表里的文件，而不是空白处

### Q: 标签盒里的标签拖不动
A: 
1. 确保没有在框选模式（按 Escape 取消框选）
2. 确保点击的是标签本身，不是标签之间的空白

### Q: 程序很卡
A: 
1. 可能是数据库太大（检查 db 文件大小）
2. 网盘文件操作可能较慢
3. 缩略图缓存可能需要重建（工具菜单 → 重建缩略图缓存）

### Q: 想撤销某个操作
A: 部分操作支持 Ctrl+Z 撤销，如标签的增删改、标签盒操作等
