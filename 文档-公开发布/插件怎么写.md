# 插件怎么写 —— 一页说明

> **★ 一句话**：往 `插件/` 目录里丢一个 `.py` 文件，
> 里面有 `register(api)` 函数，**就完了**。

---

## 最短的例子

新建 `插件/我的插件.py`：

```python
def register(api):
    api.add_menu("我的插件", [
        ("打个招呼", lambda: print("你好")),
    ])
```

**存盘、重开程序** —— 菜单里就多了一栏「我的插件」。

---

## 放哪儿

```
程序目录/
  AIxiede.py
  插件/              ← ★ 放这里
    示例插件.py       ← 有 `register(api)` 就会被加载
    _写了一半的.py    ← ★ `_` 开头 = 不加载（先放着的意思）
```

---

## `api` 能干什么（全部接口）

| 想干的事 | 怎么写 |
|---|---|
| **加一个自己的菜单** | `api.add_menu("菜单名", [("项", 函数), None, ("项2", 函数2)])` |
| **往已有菜单插一项** | `api.add_menu_item("设置", "我的设置项", 函数)` |
| **往「设置」插一项**（常用） | `api.add_settings_item("我的设置项", 函数)` |
| **给程序加一套配色** | `api.register_theme("名字", {"win_bg": "#...", "fg": "#..."}, label="显示名")` |
| **读当前皮肤颜色** | `api.theme_get("accent")` |
| **记一笔错**（会进账本） | `api.note_error("我这儿出错了", exc)` |
| **往「输出」面板写日志** | `api.log("随便写点什么")` |
| **当前在看哪个文件夹** | `api.current_dir()` |
| **现在选中了哪些文件** | `api.selected_paths()` |
| **直接拿主程序对象**（后门） | `api.app` |

**★ `None` 表示一条分隔线**（菜单里画一条横线）。

---

## ★★ 最容易忘的一件事：**把 `api` 存起来**

`register(api)` **只在启动时调一次**。之后菜单被点的时候，
`api` 这个参数早就没了 —— 所以：

```python
_API = None

def register(api):
    global _API
    _API = api          # ★★ 必须先存！
    api.add_menu("我的插件", [("看当前文件夹", _show_dir)])

def _show_dir():
    print(_API.current_dir())    # ← 这里用存下来的
```

**★ 忘了存会怎样**：点菜单时报 `'NoneType' has no attribute ...`。
**别怕 —— 程序会把错误记到账本里，但■不会崩■。**

---

## ★★★ 写坏了会怎样？（重要，先看这个）

| 情况 | 结果 |
|---|---|
| 插件**语法错** | ★ **只记一笔账，程序照常启动**（这个插件不加载） |
| 插件**运行时报错** | ★ 同上（跳过后面的插件继续加载） |
| 插件**没有 `register`** | 记一笔，跳过（**不算错误**） |
| 插件**太多/太慢** | 会拖慢启动（你自己写的，心里有数就行） |
| 插件**改了别人的东西** | `api.app` 是后门，**能改**（所以只装你信得过的插件） |

**★ 一句话：插件坏了，程序不会坏。** 我专门为这个写了兜底。

## 加配色：只要给几个色，缺的自动补

```python
api.register_theme("我的配色", {
    "name": "我的配色",
    "label": "我的配色（插件）",
    "win_bg": "#0d1b2a",      # 只给想改的
    "fg": "#dce8f5",
    "accent": "#3a86c8",
})
```

**★ 缺的键会自动从默认皮肤继承** —— 所以**不会出现"某块是白的"**
（那正是以前老出问题的原因）。
**★ 注册完，`设置 → 皮肤` 里就有了**（每次点开菜单都会重列一遍）。
