```
├────────────────────────────────────────────────────────────────────┤
│ 状态栏：显示「刚做了什么 / 出错了什么」+ 右下角转圈 = 正在忙          │

```

**三个「出主意的地方」要记住：**

| 位置 | 是什么 | 什么时候看它 |
|---|---|---|
| 状态栏（最底下那行） | 刚做完的事、报错 | 点完按钮没反应时，先看这里 |
| **🔔 问题** 按钮 | 出错/警告清单（带时间） | 程序不对劲时**第一个点这里** |
| 📋 输出 ▲ 按钮 | 程序干了什么的流水账（含「进度」页） | 想知道「它到底在干嘛」时 |
| **🏷 标签条 ▲** 按钮 | 标签条平时**藏起来**，点它才显示（整条横在窗口底部） | 想按标签筛选时 |
| **📄 预览 ▲** 按钮 | 右侧预览窗格平时**藏起来**，点它才显示 | 想一边看列表一边看文件内容时 |
| **🔖 标签库 ▲** 按钮 | 右侧「标签库（星图缩略图）」整列，可以藏起来 | 屏幕不够宽时藏起来 |
| **🧭 网盘:索引 / 网盘:真实** 按钮 | 打开网盘目录时：**索引模式秒开（不连网盘）** / 真实模式实时读（最准但慢） | 打开网盘文件夹转圈等半天时，点它切到「索引」 |

**状态栏右下角那六个按钮，从左到右是：**
`🧭 网盘`　`🔖 标签库`　`📄 预览`　`🏷 标签条`　`📋 输出`　`🔔 问题`
（▲ = 点它会显示出来，▼ = 点它会收起来）
`🧭 网盘:索引 / 🧭 网盘:真实` = **打开网盘目录「秒开还是慢吞吞」的开关**（见第 2 节第 ⑬ 条）。

**状态栏左边**分两块：**①刚做完的事**（比如「标签条：已显示」）＋**②当前视图信息**
（比如「分类「图本」：55644 个文件（含 1 个标签超链接）」「C:\Users\<用户名>  共 44 项（已刷新）」）。
第②块不会把第①块顶掉，两块并排显示。

**窗口从左到右四列**：`分类库` │ `文件列表` │ `预览窗格` │ `标签库`（后两列可以各自藏起来）
**底部**：`标签条`（可藏）在下面一层，再下面是 `📋 输出/问题` 面板（可藏），最下面是状态栏。

**标签条左边那一竖列**（从上到下）：
`标签：` → `左键筛选` → `右键屏蔽 当前页/整个视图` → `📄 范围：当前页/🗂 范围：整个视图` → `全部显示（已屏蔽 N）`

（也就是说：**范围按钮和「全部显示」按钮在左边小字的下面**，标签条最右边整段留给标签用。）

**状态栏最左**会显示两块：①刚发生的事 ②当前视图信息，例如
`标签条：已显示`　`分类「图本」：55644 个文件（含 1 个标签超链接）`。
**另外，程序现在会「自己体检」**：打开后等 3 秒，它会悄悄查一遍
（孤立标签 / 重复路径 / 坏指针 / 网盘和索引盘还在不在）。
正常就只在「📋 输出」里写一行「启动自检通过 ✓（用时 1.3 秒）」；
有问题才写进「🔔 问题」面板并告诉你该怎么办。
想随时手动查一次：菜单「标签」→「🩺 自检…」。

## 1. 数据放在哪 & 备份铁律

**四个位置，只有前两个重要：**

| 东西 | 在哪 | 重要程度 |
|---|---|---|
| **数据库**（所有标签、分类、索引都在里面） | `<数据目录>\.file_tagger.db`（约 505 MB） | ★★★★★ 丢了全完 |
| 程序本体 | `E:\桌面\MyPython\AIxiede.py` | ★★★★ 可以重下/重写 |
| 完整设置（界面缩放等） | `<数据目录>\.file_tagger_settings.json` | ★★ |
| 引导文件（只记「数据放在哪个盘」） | `C:\Users\<用户名>\.file_tagger_settings.json` | ★ 删了重新设一下就行 |

### 备份铁律（一定要养成习惯）

1. **先关程序**（不然数据库正被占用，复制出来可能是坏的）
2. 复制 `<数据目录>\.file_tagger.db`
3. 把复制出来的文件名后面加上日期，比如：
   `.file_tagger.db.bak-20260930`（只要你自己的命名，能看懂就行）
4. 放到别的盘或者别的文件夹更保险（比如 `<数据目录>\备份\`）

### 怎么恢复

1. **关掉程序**
2. 把备份文件改回原名：`.file_tagger.db`（去掉后面 `.bak-xxx` 那一段）
3. 覆盖到 `<数据目录>\` 里
4. 重新打开程序 —— 就回到备份那一刻的状态了

**什么时候必须备份**：动下面第 5 节「危险操作」之前、让我（或别人）改程序之前、换电脑/重装之前。

## 2. 日常最常用的 10 个操作（一步步）

### ① 给文件打标签
- **最快的方法**：在右边「标签库」里**按住一个标签，拖到左边文件上松手**（一次能拖到多个文件上）
- 也可以在文件上**右键 → 「添加到分类」/ 相关菜单**
- 打完标签，中间列表的「标签」列会立刻出现它

### ② 双击标签 = 看它的所有文件
在右侧标签库或标签条上**双击一个标签**，列表就变成「所有带这个标签的文件」。

### ③ 新建标签
- **菜单「标签」→「标签星图」** → 左上角「＋ 新建根标签」或「＋ 新建子标签」
- 或者在星图里**右键空白处 → 新建根标签**

### ④ 让两个标签变成父子关系（父子关系 = 会自动继承）
在星图里**把一个标签拖到另一个标签上面松手** → 前者变成后者的子标签。
- 拖上去的时候按住 **Ctrl** = 反过来（解开关系）
- 父标签的文件里，子标签的标签会**自动继承**（这是这个程序的核心机制）
- ⚠️ 一个标签可以有多个父级（比如「阅读」同时挂在「软件」和「图本」下）—— 这有用，但也容易不小心让文件跑进别的分类库（见第 7 节第 4 条）

### ⑤ 新建一个分类库（左侧那三条）
1. 左侧最下面 **「＋ 新建分类」**
2. 填名字、选个头像颜色 → 确定
3. 在分类上**右键 → 「按标签关联（超链接）…」** → 勾上「凡是含这些标签的文件都归到这个分类」
4. 保存

### ⑥ 让「自动标签规则」生效（★ 最容易被忘的一步）
规则改完**不会自己生效**。要手动跑一次：

- **菜单「界面」→「🏷 重读标签（按自动规则更新当前视图）」** = 对当前看到的这一批文件跑一遍
- **菜单「标签」→「同步所有文件的标签链」** = 全库重算一遍继承关系（慢，但最彻底）
- 或者打开 **「标签」→「⚙ 自动标签规则…」** → 用里面的「▶ 扫描选中范围 / ▶▶ 扫描全部范围」

### ⑦ 搜索文件
- 搜索框输入 → 立刻过滤当前列表（按你开启的开关：**文件名 / 标签 / 文件路径**）
- 勾上 **「含子目录」** 再按 **回车** = 搜这个目录下所有子目录（在分类库/全部文件里搜则是全库，很快）
- 搜完清空搜索框 = 回到搜索前的视图

### ⑧ 右侧「预览窗格」（看文件内容，不用打开它）

> 默认**藏起来**的。想看：点右下角 **`📄 预览 ▲`** 按钮；
> 中间列表的右边就会出现一列预览。**再点一下收起。**

- **点（单击）一个文件**，右边就会显示：
  - **文本 / 代码 / 日志**（.txt .md .py .json .log .ini .bat .html …）→ 直接看内容
    （最多显示前 256KB，太大了会提示）
  - **图片**（.jpg .png .gif .webp …）→ 显示缩略图
  - **其它**（pdf、压缩包、视频、数据库…）→ 显示它的**名称 / 路径 / 大小 / 修改时间 / 标签**，
    并提示你双击用系统程序打开
  - 选中多个文件时 → 提示「已选中 N 个」
- **宽度可以拖**：把鼠标放在预览窗格左边的分隔线上，拖成你要的宽度
- **它会记住**：你这次开的/关的状态、以及拖出来的宽度，下次打开程序还是这样
- 它**只读**，不会改动你的文件

### ⑨ 右下角那几个按钮怎么用（一句话）

| 按钮 | 点它会怎样 |
|---|---|
| `🔖 标签库 ▼/▲` | 显示 / 收起右边那列「标签库（星图缩略图）」 |
| `📄 预览 ▼/▲` | 显示 / 收起右侧预览窗格 |
| `🏷 标签条 ▼/▲` | 显示 / 收起底部那条标签条 |
| `📋 输出 ▼/▲` | 显示 / 收起底部的运行日志面板 |
| `🔔 问题 N` | 显示 / 收起「出问题和警告」清单 |

### ⑪ 文件基本操作（新建 / 改名 / 删到回收站 / 全选）

> ★ 2026-09-28 新加的第二阶段功能。**做完就可以少开资源管理器了。**

| 我想…… | 怎么做 |
|---|---|
| **新建文件夹** | 菜单「文件」→「新建文件夹」，或**右键 → 新建文件夹…**，或快捷键 **Ctrl+Shift+N** |
| **改名** | 选中**一个**文件/文件夹 → 按 **F2**，或右键 →「重命名…」（会弹小窗让你输新名字） |
| **删除** | 选中（可多选）→ 按 **Delete**，或右键 →「删除到回收站」。**会先弹确认框** |
| **全选** | 按 **Ctrl+A**，或菜单「文件」→「全选当前列表」 |
| **拉方框多选**（★ 2026-09-29/30） | **列表的左、右、下三面永远各留一条白条**（和资源管理器一个思路：左边窄、右边宽、底下一条），按住左键在白条上拖 = 拉方框；**按在文件上拖仍然是"把文件拖出去"**。文件铺满整屏时：**按住 Alt 拖**，或者把菜单「界面」→「🖱 拉框方式」切成**随处可拉**（那样在任何地方拖都拉框，拖文件出去改用 Alt+拖）。按住 **Ctrl** 拉框 = 在原选中基础上追加 |
| **复制** | 选中 → **Ctrl+C**（或菜单「文件」→「复制」） |
| **剪切（移动）** | 选中 → **Ctrl+X** |
| **粘贴** | 先打开**目标文件夹**，再按 **Ctrl+V**（或菜单「文件」→「粘贴到当前文件夹」） |

**复制/剪切/粘贴的要点：**
- 目标里**已经有同名的** → 自动叫「xxx - 副本」「xxx - 副本 (2)」，**绝不覆盖你的文件**
- **剪切 = 移动**：粘贴后原位置就没了；**移动完标签会跟着文件走**（不会丢）
- 剪切会先弹确认框；搬东西时右下角显示「正在复制/移动 N 项…」，界面不卡
- 有搬不动的（文件被占用、没权限）会列出来告诉你
- 粘贴**只在「文件夹」视图里**有效（先打开目标文件夹）
- **还差**：从资源管理器把文件拖进来 / 拖出去（要额外装个小库，见第 10 节）

**几个要点：**
- 删除是**丢进回收站**（不是永久删除），删错了去回收站还原就行
- **拉方框多选**：在列表空白处按住左键拖出虚线框（框住哪些选哪些）；按住 Ctrl 拉框 = 追加。
  点在文件上仍然是原来的「点选 / Ctrl 加减选 / Shift 连选 / 拖到资源管理器」
- 改名 / 删除之后，程序会**自动同步数据库里的路径** —— 所以你的**标签不会丢**
  （改完名，那个文件的标签照样跟着它）
- 在**搜索框里打字时，这些快捷键不会抢**（Ctrl+A 还是选文字，不会把文件全选）
- 还**没做**的：复制 / 剪切 / 粘贴（Ctrl+C / X / V）、从资源管理器拖文件进来

### ⑫ 导航 & 拖放（2026-09-28 新增）

**顶部工具栏从左到右**：`◀ 侧栏` │ 目录（地址栏） │ 浏览… │ 上一级 │ 刷新 │ **◀ 后退** │ **前进 ▶** │ **位置（盘符）** │ **常用位置** │ **⭐**

| 我想…… | 怎么做 |
|---|---|
| **回上一个文件夹** | 点「◀ 后退」或按 **Alt+←** |
| **再回到刚才那个** | 点「前进 ▶」或按 **Alt+→**（到头/到尾时按钮自动变灰） |
| **跳到某个盘** | 「位置」下拉里选（含网盘映射的 X:/Y:） |
| **跳到常用位置** | 「常用位置」下拉里选（桌面/下载/文档/主目录/索引根目录/你收藏的） |
| **把当前文件夹收进常用位置** | 点 **⭐**（会记住，下次打开还在） |
| **手输路径** | 地址栏里敲路径按回车。**粘过来带引号也行**；如果粘的是**文件**的路径，会自动进它所在文件夹 |
| **从资源管理器拖文件进来** | 直接把文件/文件夹**拖到中间的文件列表上** → 会问你要不要复制到当前文件夹（是复制，不动原文件） |
| **把文件拖出去** | 选中文件后**直接从列表拖到资源管理器/桌面** |
| **在列表里把文件挪进子文件夹** ★ | **选中文件 → 按住往列表里的那个文件夹上拖 → 松手**。会先问你一句，然后**移动**进去（原位置的东西会挪走）。拖动时列表顶上会飘一条黄字告诉你「松手 = 移动到哪」 |

### ⑲ 拉框多选怎么用（2026-09-30 改的，v25 补丁31）

| 情况 | 结果 |
|---|---|
| 在**空白处**按住左键拖 | 拉出一个方框，框住的文件全选上 |
| **按住 Alt** 在**任何地方**拖 | 一样能拉框（文件铺满整屏、找不到空白时用这个） |
| 在**文件上**直接拖 | 不是拉框，是**拖动**（拖到文件夹上 = 移动；拖到窗口外 = 拖给资源管理器） |

> 以前菜单里那个「🖱 拉框方式」开关**已经删掉了** —— 现在就是上面这三种固定行为，不用再选。

### ⑱ PDF 预览 + 解压缩 + 电子书预览（2026-09-30 新增）

#### 电子书预览（EPUB / MOBI / AZW / AZW3 / FB2）★ 2026-09-30 新增

- **点一本电子书** → 右边预览窗格**当长文本显示**（每 2600 字一"页"），
  底部有「**◀ 上一页 / 下一页 ▶**」和「第 N / M 页」
- **鼠标停在电子书上** → 悬停小窗给一小段开头
- 右键 →「**📖 用系统阅读器打开这本书**」
- **不用装任何东西**：EPUB 当 zip 拆、MOBI 自己解（含 PalmDOC 压缩），
  全是程序自带的标准库做的
- 实测网盘上的真书：`世界观…科学哲学和科学史.epub`（122 页、0.8 秒）、
  `奇点临近….mobi`（7200 字、1.6 秒）、`今日简史xg.epub`（32 章、0.9 秒）
- 解析结果会缓存，翻页不会反复解析

> **回退**：`AIxiede.py.bak-补丁29后-好用的-20260930-0900`

#### PDF 预览

- **点一个 PDF** → 右边预览窗格里**直接把第一页画出来**，下面有
  「**◀ 上一页 / 下一页 ▶**」按钮可以翻页（标题写着「PDF 第 N / M 页」）
- **鼠标停在 PDF 上**（悬停预览）也能出第一页，瞄一眼就走
- 渲染速度实测 0.01 秒一页，不会卡

> 用的是 PyMuPDF（装在你 E 盘的 libs 里，19.8MB）。
> **EPUB / MOBI 还没做** —— 它们是电子书格式，要另外解析，等你有需要再说。

#### 解压缩

**在压缩包上点右键**，菜单里多两项：

| 菜单项 | 效果 |
|---|---|
| **📦 解压到当前文件夹** | 在当前文件夹里建一个**和压缩包同名**的子文件夹，解开放在里面 |

## 3. ★自动打标签的三种方式（最容易搞错的地方）

程序里「自动打标签」有**三套完全不同的机制**，经常被搞混：

| # | 机制 | 在哪儿设置 | 什么时候生效 | 存进库里的标记 |
|---|---|---|---|---|
| 1 | **自动标签规则** | 菜单「标签」→「⚙ 自动标签规则…」 | 手动「重读标签 / 扫描范围」；或闲时自动跑 | `is_auto=2` |
| 2 | **文件名规则** | 「⚙ 自动标签规则…」窗口里点「📝 文件名规则…」 | 手动「▶▶ 应用文件名规则」；或闲时自动跑 | `is_auto=3` |
| 3 | **父标签继承** | 星图里拖出来的父子关系 | 上面两种打完标签后**自动补** | `is_auto=1` |

**简单记法**：规则负责「哪些文件该有什么标签」，父子关系负责「有了子标签就顺手给父标签也打上」。
你**手动**打的标签是 `is_auto=0`，永远不会被规则误删。

### 3.1 自动标签规则怎么写（逐项说明）

在「⚙ 自动标签规则…」窗口里点 **「➕ 新建规则（点击展开）」**，一共就 5 个格子：

| 格子 | 选项 | 说明 |
|---|---|---|
| **标签：** | 点「🔍 选择…」挑一个 | 命中的文件会被打上这个标签 |
| **匹配方式：** | **文件名包含** | 匹配内容里写关键词，**多个用逗号或换行分隔 = 任一个命中就算** |
| | **扩展名** | 写 `pdf,docx` 这种（多个用逗号） |
| | **全部文件** | 这个范围内的所有文件都打上（**必须填作用范围**，否则等于全库） |
| **作用范围：** | 留空 | = **全局**（整个库都算，容易误伤别的分类库，慎用） |
| | 填路径（一行一个） | 只在这个目录及其子目录里算。可以点「浏览…」选，点「✔ 检查」看这个范围下共有多少已知文件 |
| **匹配内容：** | 关键词 / 扩展名 | 见上面；点「➕ 加一行」可以写多条 |
| **作用字段：** | **文件名** | 只看文件名（不含路径） |
| | **完整路径** | 看整个路径（**含文件名**）—— 想按「文件夹」打标签时用这个 |
| **区分大小写** | 勾选框 | 一般不用勾 |

**文件夹类标签的标准写法**（我踩过坑，照这个来）：

- 匹配方式 = **文件名包含**
- 作用字段 = **完整路径**（不能选「文件名」，否则路径里的文件夹名匹配不到）
- 匹配内容 = **「父文件夹\子文件夹」这样带一层父目录的片段**，不要只写一个光秃秃的文件夹名

> 真实教训：给「纸质游戏」下的「九宫格」写规则时，匹配内容只写了 `九宫格`，
> 结果把整个「纸质游戏」文件夹（19500 个文件）全吃掉了 —— 因为路径里到处都有这三个字。
> 改成 `纸质游戏\九宫格99999张` 才对。

**格式类标签的标准写法**：匹配方式 = 扩展名，作用范围 = 只在你要的那个文件夹。

### 3.2 文件名规则（第 2 套）

窗口里「📝 文件名规则…」→ 勾一批标签 → 保存。
之后：**文件名里只要出现这个标签的名字，就自动打上这个标签**。
（你现在靠它实现 `.pdf`、`.mobi` 这类格式标签 —— 勾的是叫「pdf」「mobi」的标签。）

⚠️ 注意它的副作用：**`.pdf` 挂在「格式」下、而「格式」挂在「图本」下**，
所以全库任何一个 PDF 都会继承到「图本」标签 —— 「图本」分类库因此比真正的图本文件夹大
（55,662 个 vs 50,690 个）。这是设计使然，不是 bug。

### 3.3 三条铁律

1. **改完规则必须手动跑一次**（第 2 节第 ⑥ 条），否则「看着像没生效」。
2. **没有作用范围的规则是全局的** —— 会污染别的分类库。
   你原来有 5 条这种老规则（#4 卫斯理/机器抉择/三体、#8 基础、#9 题库/卷子、
   #10 _log、#11 readme/read_me）；**2026-09-28 已经全部给它们套上作用范围了**
   （详见第 10 节）。以后自己新建规则，记得「作用范围」那一格别留空。
3. **规则不会删你手动打的标签**，但会把「上次是规则打的、这次不该打了」的标签撤销 ——
   所以规则写错的表现通常是「标签莫名其妙变多/变少」，改完记得再跑一遍。

- 补丁41 起，程序会**自动检查**这个值：如果你（或旧版本）填了个明显
  不对的数，程序会忽略它、按屏幕实算 —— 不会再出现「存了个错值、
  自己还不知道」。
- **字体不用你管**：程序现在会自动挑「微软雅黑」。以前会掉到
  `Microsoft JhengHei`（**繁体**版正黑），它比雅黑矮一截，所以字
  看着小 —— 补丁41 修好了，全程序统一用雅黑。

## 7. 九条铁律（想改程序/加功能前必看）

1. **`is_auto` 有四态**：`0`=手动、`1`=父标签继承、`2`=自动规则、`3`=文件名规则。
   写错值 → 重算时会被当成「不需要」删掉。
2. **`tags` 表里那列 `parent_id` 是废的**（全库 0 条有值）；真正的父子关系只在 `tag_relations`
   （所以一个标签能有多个爸爸）。
3. **给文件写完标签，必须做一次「补祖先」**（程序里的 `resync`）。
   只往 `file_tags` 插一行、不补祖先 → 分类库和标签统计都会少文件。
4. **往父子关系里挂新标签之前，先看它的祖先链里有没有「别的分类库的根标签」。**
   真实事故：「阅读」同时挂在「软件」和「图本」下，我把新标签「公版图书」挂到「阅读」下，
   结果 1507 本公版书顺着链条跑进了「软件」分类库（995 → 2499）。
5. **`files.path` 全库唯一，而且区分大小写**：改路径要先查撞车；
   网盘路径在库里是**全小写**，本地路径保留原样。
6. **改完路径/标签，分类库的数字不会立刻变**，要等后台重算。
7. **文件夹类规则要用「完整路径」+ 足够长的片段**（第 3.1 节那个「九宫格」教训）。
8. **没有作用范围的规则是全局的** —— 会污染所有分类库。
9. **规则不是自动生效的**，改完必须「重读标签」或「同步所有文件的标签链」。

## 9. 名词对照表（用人话解释）

| 名词 | 人话 |
|---|---|
| **标签** | 你自己起的分类词，比如「九宫格」「家谱族谱」 |
| **父子关系** | 标签之间的从属关系。**父标签会自动「继承」到子标签的文件上** |
| **分类库** | 左边那三个（图本 / 软件 / 桌面）。它不是单独存文件列表，而是「关联的标签+它的子孙标签命中的文件」自动算出来的 |
| **超链接（按标签关联）** | 分类库和标签之间的那根线：勾上哪些标签，这个分类就包含哪些文件 |
| **自动标签规则** | 「符合条件的文件自动打某个标签」的规则（第 3.1 节） |
| **作用范围** | 规则只管哪个目录（留空 = 全库，危险） |
| **文件名规则** | 「文件名里出现标签名就自动打上这个标签」（第 3.2 节） |
| **索引 / 索引根目录** | 程序提前把某些盘的目录清单存进数据库，这样打开就秒开，不用真去扫盘 |
| **目录缓存** | 同上，指存下来的那份目录清单（现在 107 万行） |
| **继承** | 打了子标签，父标签自动也有（这就是为什么「图本」会有 55662 个文件） |
| **is_auto** | 数据库里记「这个标签是怎么来的」的一个数字（0 手动 / 1 继承 / 2 规则 / 3 文件名） |
| **闲时任务** | 你不动键盘鼠标够久了，程序偷偷跑一遍规则/索引扫描，你一碰它就停 |
| **重读标签** | 手动让自动规则跑一遍（就是「让它生效」的按钮） |
