## 三、★★★ 打包前我**必须修**的三处（不然发出去是半残品）

| # | 原来的写法 | 后果 | 改法 |
|---|---|---|---|
| **①** | `_LIBS_DIR = r"E:\桌面\MyPython\libs"` **写死 E 盘** | 别人电脑**没这个目录** → **PIL / 拖拽 / PDF 全失效** | 先找"自己旁边"，再退回老路径 |
| **②** | 用 `__file__` 找图标/插件 | 单文件打包后 `__file__` 指向**临时目录** → **图标、插件全找不到** | 用 `sys._MEIPASS`（打包时）+ 兼容源码跑 |
| **③** | "桌面/下载"快捷方式**写死 `E:\桌面`** | 别人电脑**没 E 盘** → 那两项**直接消失** | 问 Windows 要（`%USERPROFILE%`）+ 老路径兜底 |

**★ 还有一处我确认过**：**设置和数据库**本来就存在
`%USERPROFILE%`（**不是程序目录**）→ **打包后没问题** ✔

## 四、★★★ **发出去之前，你得知道这些风险**

### ① **杀毒软件可能报毒**（**最常见的坑**）

**★ 为什么**：PyInstaller 单文件 exe 会把内容**解压到 `%TEMP%` 再运行** ——
这个行为**跟某些病毒一模一样**，所以**很容易被误报**。

**★ 会怎样**：
- Windows Defender 可能**直接删掉**（用户下载完就没了）
- 360 / 火绒可能**弹窗拦截**
- 群里的人**一看报毒就不敢用了**

**★ 建议**：
1. **先说清楚**"这是 Python 打包的，可能误报"
2. 实在不行 → **改用"文件夹模式"打包**（`--onedir`）——
   **误报率低很多**，代价是**要发一个文件夹**（压缩成 zip）
3. **★ 别加壳、别改图标**（那会让误报更严重）

### ② **92.8 MB 有点大**

**★ 为什么大**：里面装了 Python 解释器 + Tk + PIL + 一堆库。
**★ 群里发**：微信/QQ 发 92MB 文件**没问题**，但**下载慢**。
**★ 想小一点**：我可以再剔掉一些用不上的库（能到 60MB 左右）。

### ③ **第一次启动慢**（3~8 秒）

**★ 因为**单文件要先解压到 `%TEMP%`。
**★ 会怎样**：用户**双击后以为没反应，可能又双击一次**（开两个）。
**★ 建议**：发的时候**说一句**"第一次打开慢，等几秒"。

### ④ **功能上的"残缺"（重要！）**

**★ 你这台机器上只装了这些库**：
```
✔ PIL（图片）      ✔ tkinterdnd2（拖拽）    ✔ pywin32（图标）
✘ pymupdf（PDF）   ✘ docx / openpyxl（Office）   ✘ 其他
```

**★★ 所以 exe 里**没有 PDF / Office 预览** ——
程序有兜底（**不会崩**），但用户点 PDF **看不到预览**。

**★ 这不算 bug**（本来就是这样），但**别让群里的人以为"这程序不行"**。

**★ 风险**：
- **"对不对"没有客观标准** —— 用户说"不对"你就得退，

**★ 建议改成**（如果你要承诺）：
> 「**没做**的原路退；**做了但你觉得不合适**，说一声我改到你不满意为止」

**★ 为什么**：把"对错"换成"**做没做**" —— **客观、可验证、不扯皮**。

### ③ **直播附带代码链接** —— ★ **这条要小心**

**★ 问题**：你现在这个 `AIxiede.py` 里**可能有**：

- **常用位置、书签、索引过的目录**（如果跟着数据库一起发）
- **`CloudDrive2` 相关的配置**（可能有账号信息？）

**★★ 发代码之前，让我帮你过一遍"有没有泄露个人信息"** ——
这个**必须做**，不然发出去**收不回来**。

**★ 我的建议**：
