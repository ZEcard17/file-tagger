📋 AIxiede 文件标签管理器 - 使用手册

1. 认识界面

1.1 界面布局

菜单栏 + 工具栏（路径输入 / 搜索 / 视图切换）
📂 左侧分类库
├─ 分类列表
└─ 文件目录树
📄 中间文件列表
单击选中 / 双击打开
右侧显示标签条
👁 右侧预览
单击文件后
这里显示预览
🏷 标签库
所有标签列表
可拖拽
状态栏 + 标签盒（常用标签快捷打标签）

1.2 界面区域说明

区域位置作用
分类库左上方点击切换显示不同分类的文件
文件列表中间显示文件，双击打开
预览窗格右侧单击文件后显示预览内容
标签盒底部快捷给文件打标签
工具栏顶部搜索、切换视图、设置

2. 文件浏览

2.1 进入目录

双击左侧「文件目录树」中的文件夹
中间文件列表切换到该目录，显示该目录下的所有文件
文件树：
└─ 📁 电影
    ├─ 📁 科幻
    └─ 📁 动画

双击「电影」→ 显示电影下的所有文件
双击「科幻」→ 只显示科幻下的文件

2.2 切换分类

单击左侧分类库中的任意分类
分类库中该项高亮显示（蓝色背景）
中间列表显示该分类的所有文件
分类库：
⭐ 全部文件 ← 显示所有文件
🌟 科幻 ← 显示标签含"科幻"的文件
🌟 卫斯理 ← 显示标签含"卫斯理"的文件

2.3 切换视图模式

点击工具栏中的「列表」或「瀑布流」按钮
列表视图：每行一个文件，像 Windows 资源管理器
瀑布流：缩略图网格，适合看图片和视频封面

2.4 选中文件

操作效果
单击选中单个文件，右侧显示预览
Ctrl + 单击追加选中 / 取消选中
Shift + 单击范围选中（选中两次点击之间的所有文件）
鼠标拖框框选多个文件
框选后有 300ms 宽限期，不会被误当成双击

3. 文件预览

3.1 单击预览

单击文件列表中的任意文件
右侧预览窗格显示该文件的内容

3.2 不同文件的预览效果

文件类型预览内容
文本（txt/md/py...）直接显示文字内容（前256KB）
图片（jpg/png/gif...）显示缩略图，可随窗格宽度自动撑满
PDF连续滚动浏览所有页面
视频（mp4/avi/mkv...）显示视频封面缩略图
电子书（epub/mobi...）显示前几页文字
其他显示文件名、路径、大小等基本信息

3.3 预览窗格拉宽

拖动中间列表和右侧预览之间的分隔条
预览窗格变宽
→ 图片会自动撑满新宽度
→ 文字信息也会自动换行

3.4 悬停预览

把鼠标停在文件列表中的文件上，不要动，等 0.6 秒
弹出一个小的预览窗口
悬停能看到的内容：
🖼️ 图片 → 直接显示图片
📄 PDF → 显示第一页
🎬 视频 → 显示视频封面
📝 文本 → 显示前几行文字
鼠标移开，预览窗立即消失

3.5 打开文件

双击文件
用系统默认程序打开该文件
mp4 → 用 PotPlayer/VLC/默认播放器打开
jpg → 用图片查看器打开
txt → 用记事本打开

4. 标签管理

4.1 给文件打标签（最快方式）

1. 选中一个或多个文件
2. 点击底部的「标签盒」中的标签按钮
选中的文件都获得该标签
标签盒：[科幻] [卫斯理] [文学] [+更多▼]

选中 3 个文件，点击「科幻」
→ 这 3 个文件都获得「科幻」标签

4.2 拖拽标签

1. 鼠标放在文件行右侧的某个标签上（不要点击）
2. 拖动这个标签到另一个文件的标签区域
目标文件获得该标签
星际穿越.mp4  科幻 2024
                              ↑
                         拖动「科幻」到这里

结果：三体.txt 获得「科幻」标签

4.3 移除文件的标签

右键点击文件行右侧的某个标签
弹出菜单：编辑标签 / 从文件中移除 / 查看标签

4.4 标签的继承

标签关系：
小说
 └─ 科幻
   └─ 卫斯理

给文件打「卫斯理」标签后，文件同时拥有：
✓ 卫斯理（直接打的）
✓ 科幻（卫斯理的父标签，自动继承）
✓ 小说（科幻的父标签，自动继承）

4.5 创建新标签

方法1：右键标签库 → 「新建标签」
方法2：直接给不存在的标签打标签时，会自动创建

4.6 标签星图

点击菜单「工具」→「🏷 标签星图」
打开新窗口，以星形图显示所有标签及其关系
可视化效果：
           小说
           |
           科幻
           |
     卫斯理 —— 刘慈欣

5. 分类管理

5.1 创建分类

1. 点击分类库最下方的「＋ 新建分类」
2. 输入分类名称、选择颜色和图标
新分类出现在分类库中

5.2 把文件添加到分类

方法1：拖拽
  选中文件 → 拖到左侧分类上

方法2：右键菜单
  右键文件 → 「添加到分类」→ 选择目标分类
选中 2 个文件，拖到「科幻」分类上
→ 这 2 个文件被添加到「科幻」分类

5.3 分类关联标签

1. 在分类库中右键点击分类
2. 选择「关联标签」
3. 勾选要关联的标签
该分类下的文件会自动显示这些标签
分类「科幻」关联了「科幻」和「小说」标签
把「星际穿越.mp4」添加到「科幻」分类后：
→ 文件显示：星际穿越.mp4  科幻 小说

5.4 编辑/删除分类

在分类库中右键点击分类
菜单选项：打开 / 编辑 / 关联标签 / 清空成员 / 删除分类
（清空和删除只影响分类，不影响文件本身）

6. 搜索和筛选

6.1 按文件名搜索

点击工具栏搜索框，输入文件名的一部分
列表实时过滤，只显示文件名包含搜索文字的文件
搜索「星际」→ 只显示「星际穿越.mp4」
搜索空 → 显示所有文件

6.2 按标签筛选

点击文件列表上方的标签筛选栏中的标签
勾选「科幻」→ 只显示含有「科幻」标签的文件
勾选多个 → 显示同时含有这些标签的文件（AND关系）
筛选栏：[🏷 科幻 ☑] [🏷 卫斯理 ☐]
                                      ↑
                                      勾选后只显示含「科幻」的文件

6.3 清除筛选

点击搜索框右侧的「×」或筛选栏的「重置」
恢复显示所有文件

7. 网盘文件

7.1 网盘文件预览

单击文件 → 右侧预览显示缩略图
视频预览 → cv2 直接解码，无需下载
图片预览 → 直接显示

7.2 本地缓存

首次预览时拷贝到本地临时目录
→ 第一次稍慢（需要拷贝）
→ 之后再次预览秒开（读本地副本）

8. 常用技巧

8.1 快速给多个文件打标签

框选多个文件
→
点击标签盒中的标签
→
全部获得该标签

8.2 利用继承简化标签

建议建立标签层级：

小说
 ├─ 科幻
 │  ├─ 卫斯理
 │  └─ 刘慈欣
 └─ 文学
    ├─ 托尔斯泰
    └─ 陀思妥耶夫斯基

给「基地系列」打标签 = 同时拥有「基地系列」「科幻」「文学」「小说」

8.3 用分类组织文件

创建分类
→
添加相关文件
→
点击分类快速查看

8.4 利用自动标签规则

工具 → 自动标签规则
规则示例：
文件名包含「科幻」 → 自动打「科幻」标签
扩展名是 .epub → 自动打「电子书」标签

新文件入库时自动打标签，省去手动操作

8.5 拖动分栏条调整布局

拖动各区域之间的分隔条
分类库 | 文件列表 | 预览窗格 | 标签库
↑
拖动这里可以改变各区域宽度

快捷键

快捷键功能
Ctrl + A全选
Ctrl + C复制文件路径
Delete从列表移除（不删除文件本身）
F5刷新当前目录
Escape取消选中

常见问题

Q: 为什么视频预览是静态图而不是播放？
A: 程序显示的是视频的缩略图（封面），双击文件才能用播放器播放完整视频。
Q: 为什么分类库下面的文件树是空的？
A: 文件树显示的是当前数据库中已索引的目录。确保文件已经被程序管理。
Q: 标签后面的数字是什么意思？
A: 表示使用该标签的文件数量。
Q: 可以给文件夹打标签吗？
A: 目前只支持给单个文件打标签。文件夹用于在文件树中导航。
