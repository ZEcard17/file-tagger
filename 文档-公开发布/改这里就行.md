## ★ 一、改界面上的**文字** / Changing UI text

**★★ 大部分界面文字都走 `T()` 了** —— 所以**绝大多数情况你不用改代码**：

```
★ 想换一种说法 → 改 语言/zh_CN.json（原文）+ 语言/en_US.json（译文）
★ 想加语言     → 加一个 json
```

**★ 但如果是**新加**的文字**，代码里要这样写：
```python
ttk.Label(parent, text=T("我的新按钮"))
```

**★★★ 三个必须知道的坑**（都是真踩过的）：

```python
# ✔ 对的：所有段都在 T() 的同一对括号里
text=T("第一段\n"
       "第二段")

# ★★★ 错的：T() 只包了第一段！
#   拼起来之后整串在表里查不到 → 显示的还是中文（而且半英半中）
text=T("第一段\n" "第二段")
#           ↑ 这里 T 就闭合了，第二段是**裸字符串**

# ✔ 对的：带变量的用 {} 占位符
text=T("已选中 {n} 个文件", n=count)
# ★ 不要用 % 格式化（不同语言语序不同）
```

**★ 英文表里加 key 时**：
```
★★ key 必须跟 T() **运行时真正收到的那串**一模一样 ——
   最可靠的办法：跑 `python AIxiede.py --i18n-check`，
   或者看程序日志里"没翻到"的原文。**★ 别手抄。**
```
（★ 这条是错题本 #156，我为此绕了三轮。）

## ★ 二、加一个**菜单项** / Adding a menu item

**★ 位置**：搜 `def _build_menu`（约第 26350 行）

```python
m_help.add_command(label=T("我的新菜单"), command=self.my_new_thing)
```

**★ 注意**：
- ★ **一定要 `T()`** —— 不然英文界面里它是中文
- ★ **别写在 `_menu_state_map2` 之外的地方**（那个表管"勾选状态"刷新）
- ★★ 如果菜单项**会根据状态改文字**，要**存已经翻译好的**：
  ```python
  # ✔ 对（每次打开菜单都会重设，所以要存译好的）
  _menu_state_map2.append((idx, getter, T("目录缓存"), menu))
  ```
  （★ 这条是错题本 #154。）

## ★ 三、加一个**对话框 / 窗口** / Adding a dialog

**★★ 最好的抄写对象**：搜 `def show_about`（约第 28049 行）

**★ 照这个骨架写**：
```python
def my_dialog(self):
    win = tk.Toplevel(self.root)
    win.title(T("我的窗口"))
    win.transient(self.root)
    # ★★ Toplevel 是原生窗口，底色必须自己设（错题本 #92）
    try:
        win.configure(bg=theme_get("win_bg"))
    except Exception:
        pass
    # ★★ 登记一下，切主题时才会跟着变
    try:
        _reg = getattr(self, "_theme_windows", None)
        if _reg is None:
            _reg = self._theme_windows = []
        _reg.append(win)
    except Exception:
        pass

    body = ttk.Frame(win, padding=16)
    body.pack(fill="both", expand=True)
    # …你的控件…
    ttk.Button(body, text=T("确定"), command=win.destroy).pack()
```

**★★★ 四个必须做的**：
| # | 做什么 | 忘了会怎样 |
|---|---|---|
| 1 | `win.configure(bg=theme_get("win_bg"))` | ★ 夜里**整片白**（错题本 #92）|
| 2 | 登记到 `self._theme_windows` | ★ 切主题时**它不变** |
| 3 | 所有文字包 `T()` | ★ 英文界面里是中文 |
| 4 | `tk.Text` **必须给 `width`** | ★ 不给就默认 80 字符 ≈ **884 像素**，窗口"莫名其妙很宽" |

## ★ 四、改**颜色 / 主题** / Changing colours

**★ 位置**：搜 `def _apply_theme_constants`（或 `theme_get`）

```python
theme_get("win_bg")     # 窗口底色
theme_get("fg")         # 主文字
theme_get("fg_dim")     # 次要文字（灰一点）
theme_get("text_bg")    # 文本框底色
```

**★★ 铁律**：**不要写死颜色**（`"#ffffff"`）—— 一律走 `theme_get()`。
★ 写死的话**夜间模式里就会刺眼**。

## ★ 五、加一个**快捷键** / Adding a shortcut

**★ 位置**：搜 `def _bind_shortcuts` 或 `DefShortcuts`

**★ 建议**：
- ★ **先加到默认表里**（`DEFAULT_SHORTCUTS` 之类），**然后在「快捷键管理」窗口里就能改**
- ★ 不要直接 `root.bind(...)` —— 那样用户**改不了**

**★ 位置**：搜 `class FloatingBall`（约第 24942 行）

| 想改什么 | 搜什么 |
|---|---|

★ 因为**模块级常量不能在建的时候翻**（那时语言还没定，错题本 #153）。

## ★ 八、改**索引 / 扫描** / Indexing

**★ 位置**：搜 `class IndexManagerDialog`（约第 22871 行）· 搜 `_on_idle_index_done`

**★★ 注意**：
- ★ **索引跑在后台线程里** —— **绝对不能在里面碰 Tk 控件**
  （错题本：Tk 不是线程安全的）
- ★★ 正确做法：后台线程塞 `queue` → 主线程用 `after()` 取出来再改界面

## ★ 九、加一个**设置项** / Adding a setting

```python
# 读 / read
value = load_ui_setting("my_key", "默认值")
# 写 / write
save_ui_setting("my_key", value)
```

**★★ 不要自己开文件存** —— 走这两个函数，才会存到**用户的数据目录**里。
**★★★ 更不要写死路径**（★ 别人的电脑没那个盘）。

## ★ 十、改**打包 / 发布** / Packaging

**★ 位置**：`工具/打包exe.py`（★ 长期保留的脚本）

**★★ 参数是试出来的**，别自己拼：
```
--collect-all PIL tkinterdnd2     ← 它们有数据文件，光分析抓不全
--hidden-import win32*            ← 动态导入的抓不到
--add-data 语言                   ← ★ 少了就只有中文
--add-data 图标资产                ← ★ 少了图标全变 emoji
```

**★★ 打完必须验两件事**（脚本里已经做了）：
1. ★★ **隐私扫描** —— 在 exe 字节里搜你的私人路径，**必须 0 命中**
2. ★ **关键文件在不在** —— `en_US.json` / `i18n.py` / `_icons_data.py` …
