## 一、标签星图（右侧那块）

### 1.1 标签不容易被选中 `⏳ 没做`

```
★ 看到什么:
   想点中一个标签很难 —— 鼠标明明在标签上面，点下去却没反应；
   或者要点偏一点才选中。★ 标签越小越明显。
★ 我希望:
   点到标签的**任何位置**都能选中（包括颜色块的边缘），
   **不要**要求精确命中某一条线或某个字。
★ 猜测原因（供参考）:
   命中判断可能只认"文字那一行"或者"某个矩形"，
   而不是"整个标签块的矩形范围"。
```

### 1.2 空格键拖动不跟手 `⏳ 没做`

```
★ 看到什么:
   按住空格 + 拖动鼠标来平移画布 —— 画面**慢半拍**，
   拖动时画面移动的量和鼠标移动的量对不上，感觉"黏"。
★ 我希望:
   拖多少、画面就走多少 —— **完全跟手**，不要有任何迟滞。
   （★ 就像在手机上看地图那样：手指和地图是黏在一起的。）
★ 猜测原因（供参考）:
   拖动过程中可能在**每次都重画所有标签**，
   或者有"防抖/节流"把连续的动作合并了 —— 合并可以，
   但**最后一定要落在鼠标真正停下的那个位置**。
```

### 1.3 画布无限大 + 无限缩放 `✅ 做了但我还不满意`

```
★ 现状: 上次已经改成 0.05~40 倍 + 四周留 4000 空白 —— 好了一些。
★ 我希望: 再确认"拖到边也永远拖不到头"，而且**缩放要平滑**
   （不要一格一格跳）。★ 配合 1.2 一起改。
```

## 二、文件列表

### 2.1 列拉宽之后，拖拽有"漂移" `⏳ 没做`

```
★ 看到什么:
   把「名称 / 类型 / 大小 / 所在位置 / 标签」这几列**拉得很大**之后，
   在列表里拖动（选文件 / 拖标签）时，鼠标位置和**实际选中的东西**
   对不上 —— 就像"影子"和"人"分家了。
   ★ 列越宽、偏得越多。
★ 我希望:
   不管列拉多宽，**鼠标指哪儿就选中哪儿**。
★ 猜测原因（供参考）:
   算"鼠标在第几行/第几列"的时候，可能用了**固定的列宽**
   （或者记着老宽度没更新），而屏幕上的列**已经变宽了** ——
   于是算出来的位置**偏了**。
   ★★ 这类"缓存了尺寸但没更新"以前踩过（错题本 #8 缓存键）。
```

## 三、底部状态栏与区域按钮条

### 3.1 「统计分类中…（3/3）」耗时 3.7 秒 —— 重复刷屏 `⏳ 没做`

```
★ 看到什么:
   底下连着出现两条一模一样的
   「统计分类中…（3/3）」耗时 3.7 秒（偏慢）
★ 我希望:
   · 同样的提示**不要连着重复**（合并成一条，或者第二次不报）；
   · ★★ 而且 3.7 秒确实偏慢 —— 希望**真的变快**，
     不只是"少报几条"。
★ 附注: 我上次已经加了「分类统计间隔」设置（默认 30 分钟），
   ★ 但**它算的时候本身还是慢**。
```

### 3.2 按钮条有时候会被吞字 `⏳ 没做`

```
★ 看到什么（这一条是按钮条）:
   撤销 | 标签盒 | 标签库 | 标签条 | 预览 | 顶部 | 网盘:索引 | 问题 2
   —— 这些按钮的**文字有时候只显示一半**，或者整个字不见了
   （★ 尤其窗口不够宽、或者字数多的时候）。
★ 我希望:
   · 文字**永远完整**（宁可按钮变大，也不要吞字）；
   · ★ 实在放不下时，**自动换成短名或图标**（比如"网盘:索引"→"索引"），
     而不是"切掉一半"。
★ 另外: 最后那个「问题 2」的 **2** 是什么？
   如果是"有 2 个问题"，希望能看得懂一点（★ 加个提示）。
```

### 3.3 底部信息太挤 `⏳ 没做`

```
★ 看到什么:
   最后一行挤了一大堆东西（路径 + 共 13 项 + 索引显示 + 扫描目录 + 一堆按钮），
   ★ 路径长的时候把别的东西挤没了。
★ 我希望:

   不要让它把右边的按钮挤掉。
```

## 六、悬浮球

> ★★ 这一块是**问题最多、最需要重做**的。
> 下面 5 条其实是一件事：**"形状"和"显示内容"现在互相打架**。

### 6.1 每个形状都被拉成长条 `⏳ 没做`

```
★ 看到什么:
   每个形状**都十分方正、长的很长方形** ——
   然后在那个长方形**里面再贴边描一个形**
   （在长方形底纹内画一个顶格的圆形/圆角方形）。
   ★ 也就是"外框是长的、里面那个形是正常的" —— 两层，很怪。
★ 我希望:
   · **形状本身就该是那个形状** ——
     选圆形就是圆、选方形就是方，
     ★★ **不要外面套一个长方形底纹**；
   · 方形/圆角方形**不用再画里面的形**（它本身就是方形）。
```

### 6.2 圆的功能应该钉死 = 只有三道杠 `⏳ 没做`

```
★ 看到什么:
   只要不是"只显示三道杠"，**所有的圆形都会变成椭圆**。
★ 我希望（我的原话）:
   **"圆的就应该钉死只有三道杠能显示"** ——
   · 形状 = 圆形 → **只允许显示"三道杠"**；
   · 想显示网速/硬盘/内存 → **必须换成方形/圆角方形**。
   ★ 不要让"圆"去承担"显示数字"的活儿（它会被拉成椭圆）。
```

### 6.3 方的功能应该钉死 = 有数字时不能有三道杠 `⏳ 没做`

```
★ 我希望（我的原话，分三层）:
   ① **方形/圆角方形** → 只要有
      「网速↑↓ / 硬盘读写 R/W / 内存」**任意一个**在显示，
      **三道杠就不能出现**；
   ② 这三样**同时显示不止一个**时 → **自动换行**；
   ③ 换行之后 → **左对齐**显示。
★ 一句话: **"三道杠"是圆形的专属；方形是"数据面板"。**
```

### 6.4 网速、硬盘速度**显示的不是真的** + 刷太快 `⏳ 没做`

```
★★★ 这条最要命（我的原话）:
   「网速、硬盘速度显示不对、**不是真的数值**，只有内存是对的」
★ 我希望:
   · **必须是真的**（★ 网速 = 真实的上下行速率；
     硬盘 = 真实的读写速率）；
   · ★★ **刷新别那么快** —— "对于一些人来说眼睛跟不上"。
     建议 **1~2 秒刷一次**就够了。
★ 附注: 截图里显示「11.8 KB/s ↑ 2.3 KB/s」——
   ★ 我怀疑它读的不是真网速（或者读错了网卡 / 算错了时间差）。
```

### 6.5 数值跳动时，不该带着符号一起跳 `⏳ 没做`

```
★ 我的原话:
   「显示的数值应该有一定的**固定感**，虽然数字在动，
     但**箭头、/s 之类的不应该一直随着值而跳动**」
★ 我希望:
   · 数字的**位数固定**（比如永远 `00.0`），
     这样数字变的时候**它自己内部变**，外面框不跟着跳；
   · 「↑」「↓」「R/W」「/s」这些**标签一个字都不许动**；
   · ★ 数值变化**不要改变整体宽度**
     （宽度一变，旁边的元素就会被推来推去）。
★ 一句话: **"动的是数字，不动的是版式"。**
```

## 七、夜间模式的"白底"问题

### 7.1 左边那个菜单（分类栏）**还是白底** `⏳ 没做`

```
★ 我的原话:
   「左菜单夜间模式还是白底的，**就不能和右菜单一样是黑底白字的吗**」
★ 看到什么（看截图）:
   夜间模式下 ——
   · 最左边那一竖条（全部文件 / 图本 50131 / 软件 5232 / 桌面 / ＋新建分类）
     **整片是白的**；
   · ★★ 但它**下面**的「文件目录」（目录树）却是正常深色的。
   ★ 也就是**同一根侧栏，上半截白、下半截黑** —— 很难看。
★ 我希望:
   跟右边一样 —— **黑底白字**。
★ 猜测原因（供参考）:
   那一块用的是 `tk.Frame` / `tk.Label` 这类**原生控件**，
   ★★ 它们**不吃 ttk 主题**，必须手工 `bg=theme_get(...)`
   （错题本 #4「原生控件不跟主题」就是这个）。
   ★ 而且它有个"切主题时重新上色"的登记表（`_retheme_custom_parts`），
     很可能**这块没登记进去**。
```

### 7.2 夜间模式下**很多窗口的标题栏还是白底** `⏳ 没做`

```
★★★ 我的原话:
   「夜间模式下还是有不少窗口的标题栏是白底的，
     **包括主程序也要点击一下标题栏才能变成黑底白字**」
★ 看到什么:
   · 主程序：刚打开时标题栏**白的**，★ **点一下它才变黑**；
   · 各种子窗口（对话框）的标题栏 **一直是白的**。
★ 我希望:
   夜间模式下，**所有窗口**（主窗口 + 每个对话框/子弹窗）
   标题栏**一打开就是深色**，不用点。
★ ★★★ 这条我已经**查清楚原因了**（技术结论，供参考）:
   程序里**已经有**让 Windows 标题栏变深的代码 ——
   `DwmSetWindowAttribute(hwnd, 20, 1)`（Windows 的"沉浸式深色标题栏"）。
   ★★ 但它**只对主窗口调了一次**（在换皮肤的时候），
     **所有子窗口都没调**。
   ★ 而且主窗口那次调用**时机太早**（窗口还没映射好），
     所以"点一下才变黑"—— 点击触发了 Windows 重画。
★ 修的方向（三个要点）:
   ① 每个 `Toplevel` / 对话框**都要调一次**；
   ② 调用要**等窗口真的映射出来之后**（`winfo_id()` 有 `.` 父窗口时才对）；
   ③ 还要处理"**换皮肤时重调**"（白天→夜间要变深，夜间→白天要变浅）。
```
