## 二、数据来源（**已经实测过，不是猜的**）

### 网速 —— ✅ 能用，**每秒刷新**
```
用 ctypes 直接问 Windows（GetIfTable2）：
   网卡数: 40
   网速: 下行 305.2 KB/s, 上行 551.8 KB/s
```
**★ 优点**：**不起进程**，纯读内存，**每秒刷不卡**。

### 硬盘读写 —— ⚠️ 能用，但**只能 5 秒刷一次**
```
typeperf 一次耗时: 1.26 秒        ← ★ 太慢，不能每秒调
（读 0.0 KB/s, 写 317719 KB/s 这次是拿到了）
```
**★ 试过 ctypes 走 `IOCTL_DISK_PERFORMANCE`** → **错误码 6（要管理员权限）**，行不通。
**★ 折中**：**后台线程每 5 秒跑一次 `typeperf`**，结果缓存起来显示。
**★ 好处**：跑在后台线程，**不卡界面**。

### 内存（顺手能拿，如果需要）

## 三、悬浮球长什么样

### 外观
- **圆形**，底色跟主题走（浅色/夜间自动）
- **默认内容**：`☰`（三道杠）
- **可以额外显示**（用户自选，见「显示模式」）

### 位置
- **第一次**：文件列表右侧空白区（预览/标签库那一带的左边缘）
- **拖动**：按住**拖到窗口内任何地方**（不吸边）
- **记住**：松开就存进设置，**下次打开在这儿**
- **★ 容错**：如果记住的位置**跑到窗口外面了**（比如换了显示器、窗口变小了），
  就**自动拉回可见区域** —— 免得"球不见了，找不回来"

### 左键 → 主菜单
**照搬现在的 9 大类**（不能漏一个功能）：
```
文件 / 编辑 / 标签 / 区域开关 / 用户数据 / 设置 / 刷新 / 诊断 / 帮助
```
★ 一共 **37 个可点入口 + 13 个子菜单** —— 我数过的，**一个不少地搬过去**。

### 右键 → 设置菜单（你新要的）
```
┌─────────────────────────┐
│ 皮肤        ▸  白天 / 夜间 / 跟随系统 │
│ 透明度      ▸  100% / 90% / 80% / 70% / 50% │
│ ─────────────────────── │
│ 显示什么    ☑ 三道杠 ☰            │   ← ★ 勾选式，可多选
│            ☑ 网速 ↓↑              │
│            ☐ 硬盘读写 R/W          │
│            ☐ 内存                  │

│ 停靠位置    ▸  还原到文件列表右侧      │

│ 关闭悬浮球                        │

```
**★ "显示什么"是勾选的，可以任意组合**（你说的"各种组合显示"）：

- 三个都勾 → `☰ ↓305K ↑551K R:0 W:310K`

**★ 球会随内容自动变大变小**（显示得多就大一点）。

## 四、菜单栏怎么办（你选「折中」）

**做法**：
1. **菜单栏默认藏起来**（`root.config(menu="")`）—— **看不见那条白条**
2. **★ 按 `Alt`（单击）→ 菜单栏临时出现**；再按一次 / 选完东西 → 又藏起来
3. **原菜单代码保留**（不删）—— 因为悬浮球的菜单**直接复用它**，
   删了就得重写一遍（**没必要**）

**★ 为什么这么定**（我的理由）：
- 你要的是"**看不见两个入口**" → 藏起来就看不见了 ✔
- 我要的是"**万一球出问题还能找到功能**" → `Alt` 能唤出 ✔
- **两全**。

**★ `Alt` 这个键怎么定的**：
- 查过你的程序：**没有单独的 `Alt` 快捷键**（不会打架）
- Windows 传统：**老式程序都是 Alt 出菜单栏**（顺直觉）
- 单击才出，**`Alt`+别的键照常走原功能**（不误触）

## 六、风险 / 我不确定的地方（先说出来）

1. **37 个入口搬进菜单，菜单会很长** ——
   原来的 9 大类有子菜单，**悬浮球里也能有子菜单**（一样的），所以还好。
2. **透明度的实现** —— Tk 的窗口透明度用 `attributes("-alpha", x)`，
   **★ 我还没实测过它在这个程序里好不好使**（有些 Windows 主题会无视）。
   动手时先试，不行我就告诉你。
3. **球挡住内容** —— 你要"想去哪去哪"，所以**不拦你**；
   但如果挡住按钮了，**右键 → 关闭悬浮球** 能关掉（重新打开在「设置」菜单里）。
4. **硬盘读写 5 秒才刷一次** —— Windows 的限制（要管理员权限才能更快），
   **不是我不想做快**。
