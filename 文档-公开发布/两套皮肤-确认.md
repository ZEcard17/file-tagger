## 二、你要的应该是这样（我理解的）

| | 主界面皮肤 | 悬浮球皮肤 |
|---|---|---|
| **管什么** | 整个主窗口的颜色（列表、面板、按钮…）| **只管那个球**（圆球颜色、文字颜色、边框…）|
| **在哪改** | `设置 → 🎨 皮肤` | **球上右键 → ⚪ 球的皮肤** |
| **互相影响吗** | ❌ **不该影响球** | ❌ **不该影响主界面** |
| **各自记各自** | 存 `theme` | 存 `ball_skin` |

**★ 举例**：
- 主界面用**夜间**（深色），球可以是**亮橙色**（显眼）
- 主界面用**白天**（浅色），球可以是**半透明深灰**（低调）
- **两个随便配，互不干扰**

## 三、我打算怎么做（三件事）

### ① **球的颜色从主界面**解耦****
现在：`fill = theme_get("accent")` ← 借主界面的
改成：`fill = 球自己的颜色`（存在 `ball_skin` 里）

### ② **球的右键菜单里，把两类分清楚**
```
┌──────────────────────────────┐
│ ⚪ 球的皮肤    ▸ （改这个球自己的颜色）│ ← ★ 新增，只管球
│ ─────────────────────────── │
│ 🎨 主界面皮肤  ▸ 白天 / 夜间 / 自定义 │ ← ★ 改名（原叫"皮肤"）
│ ─────────────────────────── │
│ 透明度         ▸ 100% / 90% / …    │
│ 显示什么       ☑ 三道杠 ☑ 网速 …    │
│ 停靠位置       ▸ 放回默认位置        │
│ 菜单栏 / 关掉球                     │
└──────────────────────────────┘
```
**★ 关键改动**：
- 原来那个「皮肤」**改名叫「主界面皮肤」** —— 一眼就知道它改的是哪儿
- **新增「球的皮肤」** —— 只管球自己

### ③ **球自己的皮肤，给几套现成的**（先不搞太复杂）
```
⚪ 球的皮肤 ▸ ● 跟随主界面（默认，跟现在一样）
            ▸ ● 蓝（默认那个）
            ▸ ● 绿
            ▸ ● 橙
            ▸ ● 红
            ▸ ● 紫
            ▸ ● 深灰（低调）
            ▸ ● 浅灰（白天好看）
            ▸ ─────────────
            ▸ 🎨 自定义…（选颜色）
            ▸ ⬜ 圆 / 方形 / 无边框
```

**★ 每套球皮肤管这几个**：
- **圆球底色**
- **球的边框色**
- **球上文字的颜色**（`☰` 和那些数字）
- **形状**（圆 / 圆角方 / 方）
