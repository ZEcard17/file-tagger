## 2. 文件浏览

### 2.1 进入目录

**操作**：双击左侧「文件目录树」中的文件夹

**效果**：
- 中间文件列表切换到该目录
- 显示该目录下的所有文件

**示例**：
```
文件树：
  └─ 📁 电影
       ├─ 📁 科幻
       │    ├─ 星际穿越.mp4
       │    └─ 银翼杀手2049.mkv
       └─ 📁 动画
            └─ 你的名字.mp4

双击「电影」→ 显示 3 个视频文件
双击「科幻」→ 只显示 2 个视频文件
```

### 2.2 切换分类

**操作**：单击左侧分类库中的任意分类

**效果**：
- 分类库中该项高亮显示（蓝色背景）
- 中间列表显示该分类的所有文件

**示例**：
```
分类库：
  ⭐ 全部文件        ← 显示数据库中所有文件
  🌟 科幻           ← 显示标签含"科幻"的文件
  🌟 卫斯理         ← 显示标签含"卫斯理"的文件
  🌟 文学           ← 显示标签含"文学"的文件
```

### 2.3 切换视图模式

**操作**：点击工具栏中的「列表」或「瀑布流」按钮

**效果**：

| 视图 | 显示效果 |
|------|----------|
| 列表视图 | 每行一个文件，像 Windows 资源管理器 |
| 瀑布流 | 缩略图网格，适合看图片和视频封面 |

### 2.4 调整缩略图大小

**操作**：在瀑布流视图下，点击缩略图尺寸调节滑块

**效果**：缩略图从小到大变化（5档）

### 2.5 选中文件

| 操作 | 效果 |
|------|------|
| 单击 | 选中单个文件，右侧显示预览 |
| Ctrl + 单击 | 追加选中/取消选中 |
| Shift + 单击 | 范围选中（选中两次点击之间的所有文件） |
| 鼠标拖框 | 框选多个文件 |

**框选技巧**：
- 鼠标从空白处开始拖动，会出现蓝色选框
- 松开鼠标后，选框内的文件全部被选中
- 选中后单击空白处取消全选

## 3. 文件预览

### 3.1 单击预览

**操作**：单击文件列表中的任意文件

**效果**：右侧预览窗格显示该文件的内容

### 3.2 不同文件的预览效果

| 文件类型 | 预览内容 |
|----------|----------|
| 文本（txt/md/py...） | 直接显示文字内容（前256KB） |
| 图片（jpg/png/gif...） | 显示缩略图，可拖大缩小 |
| PDF | 连续滚动浏览所有页面 |
| 视频（mp4/avi/mkv...） | 显示视频封面缩略图 |
| 电子书（epub/mobi...） | 显示前几页文字 |
| 其他 | 显示文件名、路径、大小等基本信息 |

### 3.3 预览窗格拉宽

**操作**：拖动中间列表和右侧预览之间的分隔条

**效果**：
- 预览窗格变宽
- **图片会自动撑满新宽度**
- 文字信息也会自动换行

### 3.4 悬停预览（鼠标停留）

**操作**：把鼠标停在文件列表中的文件上，不要动，等 0.6 秒

**效果**：弹出一个小的预览窗口，显示：
- 图片：直接显示图片
- PDF：显示第一页
- 视频：显示视频封面
- 文本：显示前几行文字

**取消**：鼠标移开，预览窗立即消失

### 3.5 打开文件

**操作**：双击文件

**效果**：用系统默认程序打开该文件

**示例**：
- mp4 → 用 PotPlayer/VLC/默认播放器打开
- jpg → 用图片查看器打开
- txt → 用记事本打开

## 4. 标签管理

### 4.1 给文件打标签

**方法一：标签盒（最快）**

1. 选中一个或多个文件
2. 点击底部的「标签盒」中的标签按钮

```
标签盒：[科幻] [卫斯理] [文学] [+更多▼]
              ↑    ↑     ↑
              点击哪个，哪个标签就打到文件上了
```

**效果**：选中的文件都获得该标签

---

**方法二：拖拽标签**

1. 在文件列表中找到带标签的文件（标签显示在文件名后面）
2. 鼠标放在标签上（不要点击）
3. 拖动标签到目标文件上

```
原文件：星际穿越.mp4  🏷科幻 🏷2024
                                     ↑
拖动「科幻」标签，拖到这里         │
然后松开                              │
↓                                     ↓
目标文件：三体.txt  （还没有标签）→ 三体.txt  🏷科幻
```

---

**方法三：右键菜单**

1. 右键点击文件
2. 选择「🏷 添加标签」
3. 输入标签名或选择已有标签

### 4.2 移除文件的标签

**操作**：在文件行右侧的标签条上，右键点击某个标签

**效果菜单**：
- 编辑标签 → 修改标签名称/颜色
- 从文件中移除 → 只移除这一个文件的标签（不影响其他文件）
- 查看标签 → 跳转到该标签的筛选视图

### 4.3 查看所有标签

**操作**：点击右侧「标签库」区域（窗口最右侧）

**效果**：
- 显示所有已创建的标签
- 每个标签显示名称和颜色
- 标签后面的数字表示使用该标签的文件数量

### 4.4 标签的继承

如果标签之间有父子关系，给文件打子标签时，父标签会自动继承。

```
标签关系：
  小说
    └─ 科幻
          └─ 卫斯理

给文件打「卫斯理」标签后，文件同时拥有：
  ✓ 卫斯理（直接打的）
  ✓ 科幻（卫斯理的父标签，自动继承）
  ✓ 小说（科幻的父标签，自动继承）
```

### 4.5 创建新标签

**操作**：在标签库区域，右键 → 「新建标签」

或：直接给不存在的标签打标签时，会自动创建

### 4.6 编辑标签

**操作**：在标签库区域，右键点击标签

**可修改**：
- 标签名称
- 标签颜色
- 父标签（建立继承关系）

### 4.7 标签星图

**操作**：点击菜单「工具」→「🏷 标签星图」

**效果**：打开一个新窗口，以星形图显示所有标签及其关系

**操作**：
- 拖动标签节点可以调整位置
- 双击节点可以展开/折叠子标签
- 右键节点可以编辑/删除

## 5. 分类管理

### 5.1 创建分类

**操作**：
1. 在左侧分类库最下方，点击「＋ 新建分类」
2. 输入分类名称
3. 选择分类颜色和图标

**效果**：新分类出现在分类库中

### 5.2 把文件添加到分类

**方法一：拖拽**

1. 选中文件
2. 拖到左侧分类库中的某个分类上

```
文件列表：☑ 星际穿越.mp4  ☑ 三体.txt
                          ↓
分类库：  科幻 ← 拖到这里松开
                         ↓
结果：星际穿越和三体都被添加到「科幻」分类
```

---

**方法二：右键菜单**

1. 右键点击文件（可以是多选）
2. 选择「添加到分类」
3. 选择目标分类

### 5.3 分类关联标签

**概念**：分类可以关联标签，这样该分类下的文件会自动显示这些标签

**操作**：
1. 在分类库中右键点击分类
2. 选择「关联标签」
3. 勾选要关联的标签

**效果**：
```
分类「科幻」关联了标签「科幻」和「小说」

把「星际穿越.mp4」添加到「科幻」分类后：
  - 文件在列表中显示：星际穿越.mp4  🏷科幻 🏷小说
  - 自动获得「科幻」和「小说」两个标签
```

### 5.4 编辑/删除分类

**操作**：在分类库中右键点击分类

**菜单**：
- 打开 → 切换到该分类的视图
- 编辑 → 修改分类名称/颜色/图标
- 关联标签 → 增删该分类的关联标签
- 清空成员 → 移除该分类的所有文件（文件本身不删除）
- 删除分类 → 删除分类（文件本身不删除）

## 6. 搜索和筛选

### 6.1 按文件名搜索

**操作**：
1. 点击工具栏的搜索框
2. 输入文件名的一部分

**效果**：列表实时过滤，只显示文件名包含搜索文字的文件

**示例**：
```
搜索「星际」→ 只显示「星际穿越.mp4」
搜索空 → 显示所有文件
```

### 6.2 按标签筛选

**操作**：
1. 在文件列表上方，有一行标签筛选栏
2. 点击标签按钮激活筛选

**效果**：
```
筛选栏：[🏷 科幻 ☑] [🏷 卫斯理 ☐] [🏷 文学 ☐]
                  ↑           ↑         ↑
                 勾选        未选      未选

只显示含有「科幻」标签的文件
如果多个勾选，显示同时含有这些标签的文件（AND关系）
```

### 6.3 清除筛选

**操作**：
- 点击搜索框右侧的「×」按钮
- 或点击筛选栏右侧的「重置」

**效果**：恢复显示所有文件

### 6.4 搜索技巧

| 搜索内容 | 输入示例 |
|----------|----------|
| 文件名包含 | `星际` `三体` |
| 扩展名过滤 | `.mp4` `.txt` |
| 组合搜索 | 先选标签，再搜文件名 |

## 7. 网盘文件

### 7.1 网盘文件的特点

程序支持访问网盘路径（如 `\\CloudDrive\X\...`）

**预览效果**：
- 单击文件 → 右侧预览窗格显示缩略图
- 视频预览 → cv2 直接解码，无需下载
- 图片预览 → 直接显示

### 7.2 本地缓存

网盘文件首次预览时，会拷贝到本地临时目录

**效果**：
- 第一次预览稍慢（需要拷贝）
- 之后再次预览秒开（直接读本地副本）

### 7.3 缓存清理

程序启动时自动清理旧的临时文件，不需要手动处理

## 8. 常用技巧

### 8.1 快速给多个文件打标签

1. 框选或 Ctrl+点击选中多个文件
2. 点击标签盒中的标签

**效果**：所有选中文件同时获得该标签

### 8.2 批量添加到分类

1. 选中多个文件
2. 拖拽到左侧分类上

### 8.3 利用继承简化标签

**建议**：建立标签层级，减少重复打标签

```
.baduk
  ├─ 科幻
  │    ├─ 卫斯理
  │    ├─ 刘慈欣
  │    └─ 基地系列
  ├─ 文学
  │    ├─ 托尔斯泰
  │    └─ 陀思妥耶夫斯基
```

给「基地系列」打标签 = 同时拥有「基地系列」「科幻」「文学」「小说」

### 8.4 用分类组织文件

**场景**：想把某批文件归到同一个项目下

1. 创建一个分类「项目A」
2. 把相关文件添加到这个分类
3. 点击分类即可快速查看该项目所有文件

### 8.5 利用自动标签规则

**操作**：工具 → 自动标签规则

**用途**：
- 文件名包含「科幻」→ 自动打「科幻」标签
- 扩展名是 .epub → 自动打「电子书」标签

**效果**：新文件入库时自动打标签，省去手动操作

### 8.6 框选后不要急着点击

框选文件后，会有 **300 毫秒的宽限期**。

这是为了防止：框选完成后，鼠标抬起时误触发的单击被当成双击。

**放心**：框选完成后直接进行下一步操作即可。

### 8.7 拖动分栏条调整布局

**操作**：拖动三个区域之间的分隔条

```
分类库 | 文件列表 | 预览窗格 | 标签库
        ↑
   拖动这里可以改变各区域宽度
```

**效果**：
- 可以把分类库调窄，文件列表调宽
- 可以隐藏不需要的区域的显示

## 常见问题

**Q: 为什么视频预览是静态图而不是播放？**

A: 程序显示的是视频的缩略图（封面），双击文件才能用播放器播放完整视频。

**Q: 为什么分类库下面的文件树是空的？**

A: 文件树显示的是当前数据库中已索引的目录。确保文件已经被程序管理（添加到数据库）。

**Q: 标签后面的数字是什么意思？**

A: 表示使用该标签的文件数量。

**Q: 可以给文件夹打标签吗？**

A: 目前只支持给单个文件打标签。文件夹会显示在文件树中，用于导航。
